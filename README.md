# CoeFont通訳 参加ガイド（タイ語）

タイ側のナショナルスタッフに渡す、AI同時通訳「CoeFont通訳」の**参加者向け操作ガイド**一式です。
ゲスト側の操作だけを扱います（ホスト側＝会議の作成・通訳の開始は対象外）。

前提は **Teamsプラグイン版のデフォルトモード**（通訳開始時に、リンク・パスコード・QRが
Teamsの会議チャットへ自動投稿され、参加者はブラウザで開く方式）です。
アドバンスドモード（Teams内で直接通訳音声を聞く方式）を使う場合は手順が変わります（下記）。

作成元の指示書：`docs/20260919_指示書_CoeFont通訳_参加者ガイド.md`

## 成果物（`output/`）

| ファイル | 用途 |
|---|---|
| `CoeFont_Guide_TH_v2.pdf` | **配布用**。A4縦2ページ。タイ語（大）＋英語（小） |
| `CoeFont_Guide_TH_v2_p1.png` / `_p2.png` | 同内容の画像（幅1240px）。スマートフォンやチャットでの共有用 |
| `CoeFont_Guide_TH-JA_internal_v2.pdf` | **日本側控え**。同じ内容に日本語を併記（A4縦3ページ） |
| `thai_text_for_review.txt` | タイ語・英語・日本語の対訳一覧 |
| `build_report.json` | ビルド結果（使用した画面コピー、各ページの余白） |

## ビルドと検品

```bash
npm install          # 初回のみ（playwright 1.56.1 / sharp）
npm run build        # HTML → PDF・PNG・対訳ファイルを生成
npm run check        # 検品（フォント埋め込み・改行・ページ数など15項目）
```

- 文面・レイアウトの修正は `src/guide.html` だけを直して再ビルドします。対訳ファイルは画面表示から自動生成されるので、本文と食い違いません。
- PDF生成は Playwright（Chromium）の `page.pdf()` です。タイ語は単語の間に空白がないため、行の折り返しをブラウザに任せる必要があります（WeasyPrint等は不可）。
- フォントは Noto Sans Thai / Noto Sans / Noto Sans JP（いずれもOFL）を `assets/fonts/` に同梱し、PDFに埋め込んでいます。
- タイ語は単語の途中で改行されることがあるため、`src/enhance.js` の `NOBREAK` に列挙した語には
  不可視の word joiner (U+2060) を挿入しています。検品でも分割の有無を自動判定します。

### 画面コピー

`input/screenshots/` のPNGを差し替えて再ビルドすれば入れ替わります（`input/screenshots/README.md` 参照）。
現行のPNGは、CoeFont社の公式マニュアル（Teamsプラグイン版・デスクトップ版）から参加者画面だけを
切り出し、第三者名・デモURL・デモのパスコードをマスクしたものです。再生成する場合：

```bash
pdfimages -png -f 12 -l 15 <Teamsプラグイン版マニュアル>.pdf shots/t
pdfimages -png -f 14 -l 14 <デスクトップ版マニュアル>.pdf   shots/d
node scripts/prepare-screenshots.mjs shots
```

## 構成

```
├── src/guide.html                ← 本文・レイアウト（ここだけ直せばよい）
├── src/enhance.js                ← 画面コピー差し替え／番号丸／タイ語の禁則処理
├── scripts/build.mjs             ← PDF・PNG・対訳ファイルの生成
├── scripts/check.mjs             ← 検品（15項目）
├── scripts/prepare-screenshots.mjs ← 公式マニュアルから参加者画面を切り出し・マスク
├── assets/fonts/                 ← Noto Sans Thai / Noto Sans / Noto Sans JP
├── input/screenshots/            ← 画面コピー
├── docs/                         ← 指示書
└── output/                       ← 生成物
```

## 記載内容の根拠と、確認が必要な点

本文の手順・ボタン名は、CoeFont社マニュアルの以下の記述に基づいています。

| 本文 | 根拠 |
|---|---|
| リンク・パスコード・QRが会議チャットに出る | Teamsプラグイン版マニュアル「8. 通訳音声を聞く」 |
| `ブラウザで開く` / `チャットに再送` | 同上（チャット投稿内のボタン） |
| `音声をオンにして開始` / `テキストのみで開始` | 同「パスコードを入力します」の画面 |
| ページを離れる・再読み込みでリセット | 参加者ページ上の表示「同時通訳のライブ配信ページです。ページを離れるか再読み込みするとリセットされます。」 |
| 言語設定は画面右上 | デスクトップ版マニュアル「4. 他の会議参加者に通訳を共有する」の画面内表示 |
| タイ語対応 | Teamsプラグイン版マニュアルの言語一覧（タイ語Bot `th@cirbots.onmicrosoft.com`） |

確認が必要な点：

1. **参加者ページの表示言語**。手元の画面コピーは日本語表示です。タイ語を選んだときにボタンが
   タイ語・英語のどちらで表示されるかは未確認のため、本文には「ボタンは別の言語で表示される場合がある。
   位置とアイコンで見分ける」旨のタイ語注記を入れています。
2. **利用モード**。アドバンスドモードを使う場合、参加者はブラウザを開かず、Teamsの
   「通訳言語の選択」から言語を選ぶ方式になります。その場合は本ガイドの Step 2〜3 を差し替えます。
3. **参加者のアカウント**。個人用Microsoftアカウントでは利用できません（ホストと同じ組織、別の組織、
   またはゲストとして追加されたアカウントが必要）。タイ側の参加環境をご確認ください。
