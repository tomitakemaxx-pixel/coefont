# CoeFont Interpreter 参加者ガイド（タイ語）

タイ側ナショナルスタッフ向けの、CoeFont通訳（Teamsプラグイン版・デフォルトモード）の参加手順書です。
CoeFont社（北沢様）経由でお渡しし、タイ側のセッティングに使っていただく前提です。

## 成果物（`output/`）

| ファイル | 内容 |
|---|---|
| `CoeFont_Participant_Guide_TH.docx` | **配布用**。タイ語＋英語。A4・3ページ |
| `CoeFont_Participant_Guide_TH-JA.docx` | 同じ内容に日本語を併記した版（日本側・北沢様の確認用）。A4・4ページ |
| `TH-EN-JA_parallel_text.txt` | 全文のタイ語・英語・日本語の対訳一覧 |

PDFは、Wordで `.docx` を開き「ファイル → エクスポート → PDF/XPS の作成」で作ります。
フォントは Leelawadee UI（タイ語・英語）と 游ゴシック（日本語）で、どちらもWindows標準です。

## 構成

| ページ | 内容 |
|---|---|
| 1 | 表題・導入、1. 必要なもの（＋リンクは会議チャットに出る旨の注記）、2. 手順1〜2 |
| 2 | 手順3〜5、3. スマートフォンで使う場合 |
| 3 | 4. 困ったとき（画面に出るメッセージ別）、5. 英語の定型フレーズ |

## 編集・再作成

```bash
npm install          # 初回のみ
npm run build        # src/content.mjs → output/*.docx と対訳一覧
npm run preview      # LibreOfficeで preview/ にPNGを出力（代替フォントでの確認用）
npm run check        # 検品（16項目）
```

- 文章は `src/content.mjs` だけを直します。レイアウトは `scripts/build-docx.mjs`。
- 画面コピーは `input/screenshots/`。赤い番号丸は `src/content.mjs` の `marker`（画像の左上を 0,0 とした％）で、ビルド時に画像へ描き込みます。
- `preview/` は代替フォント（Noto Sans / IPAゴシック）での表示なので、改行位置はWordと少し異なります。

## 記載内容の根拠

| 本文 | 根拠 |
|---|---|
| リンク・パスコード・QRが会議チャットに出る、「ブラウザで開く」「チャットに再送」 | CoeFont社 Teamsプラグイン版マニュアル「8. 通訳音声を聞く」 |
| 通訳音声はページから出る、エコー防止にイヤホン | 同マニュアル（イヤホン使用の注意書き） |
| 開始ボタン「เริ่มพร้อมเสียง / เริ่มด้วยข้อความเท่านั้น」ほか画面の文言 | 参加者ページの表示文言（タイ語・英語・日本語の各言語ファイル、2026-09-24確認） |
| 参加者ページは端末の言語で表示される | 同上（ブラウザの言語をタイ語／日本語／英語にして表示を確認） |
| 言語設定は画面右上、イヤホンアイコンで音声の入切 | デスクトップ版マニュアル「4. 他の会議参加者に通訳を共有する」の画面 |
| 「ไม่พบการประชุม」「เชื่อมต่อไม่สำเร็จ」「การประชุมยังไม่เริ่ม」 | 参加者ページの表示文言（同上） |
| 文字サイズの「A+」 | 参加者ページの文字サイズ切替（Teamsプラグイン版マニュアルの画面にも表示） |

## 前提条件（ホスト側）

- Teamsプラグイン版マニュアル「3. 言語設定」で、会議の言語に**日本語とタイ語**を設定しておくこと。
  設定がないと、チャット投稿の言語タブにタイ語が出ず、参加者はタイ語を選べません。
