# Claude Code 指示書：CoeFont通訳「参加者ガイド」（タイ語・英語・日本語）の作成

作成日：2026年9月19日（土）
作成者：髙山浩和（日鉄物産 DX推進部 ビジネス企画グループ）
用途：Claude Code に本ファイルを読ませ、参加者ガイド（PDF）を作らせる。

---

## Ⅰ．目的と読み手

(1) 何を作るか
AI同時通訳「CoeFont通訳」の**参加者（ゲスト）向けガイド**。参加者が、送られてきたURL/QRコードを自分のPCブラウザまたはスマートフォンで開き、パスコードを入れ、自分の言語（タイ語）を選び、訳が画面に出るところまでを迷わずできるようにする。
**ゲスト側の操作だけ**を扱う。ホスト側（会議の作成・通訳の開始）は扱わない。

(2) 読み手
タイ現地法人のナショナルスタッフ3名（日本語不可。うち1名は英語も不十分）。
主言語＝タイ語、副言語＝英語、参考＝日本語（日本側の同席者が同じ紙を見て指示できるように）。

(3) 使う場面
① 2026年9月28日〜30日ごろ：Teams会議で日本語⇔タイ語の精度をテストする場（人事部門＋タイ側1〜3名＋CoeFont社の北沢さん＋髙山）。事前にメールで配布する。
② 2026年11月16日の週：来日時の対面研修（第2版で対応。今回は対象外）。

(4) 成功の基準
テスト当日、タイ側が「ガイドを見ながら自力でページを開き、言語を選べる」こと。操作に迷ったとき、日本側が**英語**で修正指示を出せるよう、英語の定型フレーズを載せる。

## Ⅱ．前提知識（Claude Code が知っておくべきこと）

(1) CoeFont通訳の仕組み（ゲスト側に関係する部分だけ）
- ホスト1名（日本側）がPCで通訳を起動し、参加者用の**URL・QRコード・パスコード**を発行する。
- 参加者はブラウザでそのURLを開く。**アカウント登録・アプリのインストールは不要**。
- 参加者はページで「見たい言語」を選ぶ。日本語の発言がタイ語（または英語）の文字で表示される。
- Teams会議の音声はTeamsで流れる。CoeFontのページは「訳を見る画面」として、Teamsと並べて使う。
- **イヤホン推奨**。スピーカーに出すと音が回り込む。
- ページを離れると、それまでの訳の表示は消える（ページ上にその旨の表示が出る。文言は画面コピーで確認して転記する）。

(2) 確認済みの事実（当社の検証記録）
- 2026年8月24日および9月15日のリハーサルで、参加者がQR/URL＋パスコードでブラウザ参加し、言語を選んで訳が表示されることを確認済み。PC・スマートフォンとも動作。
- 対応言語にタイ語が含まれる（CoeFont社公表）。

(3) 未確認・不明のこと（**推測で埋めない**）
- ゲストページの正確なボタン名・画面遷移・言語選択の表示ラベル → **画面コピーに写っている文言だけを使う**。
- ゲストページに音声読み上げ機能があるか、その操作 → 画面コピーに写っていなければ書かない。
- タイ側のPC/スマートフォンの機種・ブラウザ → 「Chrome / Safari / Edge のいずれか」とだけ書く。
- URL・パスコード・QRコード → 当日ホストが発行するため、**空欄（記入枠）**にする。

(4) 参考資料（髙山が用意して同じフォルダに置く）
- `input/manual_browser_ver.pdf`：CoeFont社「ブラウザ版 操作マニュアル」（2026年8月18日受領）。ホスト側の手順書だが、ゲスト参加の説明があればそこだけ参照。**このPDFの内容をそのまま転載しない**（用語の確認用）。
- `input/screenshots/`：髙山が撮る画面コピー（Ⅴ参照）。
- 公式サイト：https://coefont.cloud （製品概要の確認用。ロゴ・画像は使わない）

## Ⅲ．成果物の仕様

(1) ファイル
- `output/CoeFont_Participant_Guide_TH-EN-JA_v1.pdf`（配布用・A4縦・**2ページ以内**）
- `output/CoeFont_Participant_Guide_TH-EN-JA_v1_p1.png`, `_p2.png`（スマートフォンで見る用に各ページを画像化。幅1240px程度）
- `src/guide.html`（元データ。修正はここで行い、PDFを再生成できるようにする）

(2) 言語の扱い
- 各手順を **タイ語（大）→ 英語（中）→ 日本語（小・灰色）** の順に縦に並べる。
- タイ語の文字サイズは英語より一段大きく（目安：タイ語 15pt / 英語 11pt / 日本語 9.5pt）。
- 見出し・ステップ番号は3言語共通の数字（1〜8）にし、口頭で「Step 4」と言えば通じるようにする。
- タイ語の文は短く。1手順あたり2文以内。

(3) レイアウト
- 左：画面コピー（幅40%程度）、右：3言語の説明文、の2段組み。画面コピーがない手順は文だけ。
- 画面コピーには、押す場所に**番号付きの丸印（赤）**を重ねる。文中の番号と対応させる。
- 冒頭に「必要なもの」、末尾に「困ったとき」と「英語の定型フレーズ」を置く。
- 記入枠（URL／パスコード／QR）は1ページ目の目立つ位置に、手書きでも書ける大きさで置く。QRは、URLが確定したら `qrcode` ライブラリで生成して差し込めるようにしておく（未確定の間は空枠）。

(4) フォント（**必須**）
- タイ語：Noto Sans Thai（または Sarabun）。英語：Noto Sans。日本語：Noto Sans JP。いずれもGoogle Fonts（OFL）。
- **PDFにフォントを埋め込む**こと。タイ語は単語間に空白がないため、行の折り返しはブラウザ（Chromium）の処理に任せる。したがってPDF生成は **Playwright（Chromium）の `page.pdf()`** を使う。WeasyPrint等はタイ語の改行が崩れるおそれがあるため使わない。
- Wordで作る場合（今回は不要）：タイ語は「複合文字体系（Complex Script）」のフォント指定が別に必要。

(5) デザイン
- 白地・黒文字を基本。色は、ステップ番号の丸印（赤）と、記入枠の枠線（青）だけに使う。
- ロゴ・イラストは使わない。CoeFont社のロゴも入れない。
- フッターに「For internal use – Nippon Steel Trading Corporation / 社内利用限定」と、版（v1・2026-09）を入れる。
- **作成ツール名（Claude 等）はどこにも入れない。**

## Ⅳ．掲載内容（原稿）

日本語と英語は下記を使う。**タイ語は Claude Code が下記の英語から翻訳して作る**（Ⅵ(3)の注意を守る）。文言は「画面コピーに写っている表示」に合わせて調整してよいが、意味を足さない。

### 表紙・見出し
- JA：CoeFont通訳 参加ガイド（Teams会議用）
- EN：CoeFont Interpreter — Participant Guide (for Teams meetings)

### これは何？
- JA：AI同時通訳です。日本語の発言が、あなたの画面にタイ語（または英語）の文字で表示されます。あなたのタイ語は、日本側の画面に日本語で表示されます。
- EN：This is an AI interpreter. Japanese speech will appear on your screen as Thai (or English) text. Your Thai speech will appear on the Japanese side's screen in Japanese.

### 必要なもの
- JA：PCまたはスマートフォン（ブラウザ：Chrome / Safari / Edge）、イヤホン、インターネット接続。アカウント登録もアプリのインストールも不要です。
- EN：A PC or smartphone with a browser (Chrome / Safari / Edge), earphones, and an internet connection. No account and no app installation are needed.

### 記入枠（1ページ目）
- JA：CoeFontのリンク ／ パスコード ／ QRコード
- EN：CoeFont link / Passcode / QR code

### Step 1
- JA：Teams会議に、いつもどおり参加します。音声はTeamsを使います。
- EN：Join the Teams meeting as usual. Audio goes through Teams.

### Step 2
- JA：Teamsのチャットに届く「CoeFontのリンク」を開きます。PC：リンクをクリック。スマートフォン：カメラでQRコードを読み取る、またはリンクをタップ。
- EN：Open the CoeFont link posted in the Teams chat. PC: click the link. Smartphone: scan the QR code with your camera, or tap the link.

### Step 3
- JA：パスコードを求められたら、チャットに記載のパスコードを入力します。
- EN：If a passcode is requested, enter the passcode from the chat.

### Step 4
- JA：言語で「ไทย（タイ語）」を選びます。英語で見たい場合は「English」を選びます。
- EN：Select "ไทย (Thai)" as your language. Choose "English" if you prefer English.
（※画面コピーの言語選択の表示に合わせて、実際のラベル名で書く）

### Step 5
- JA：会議中は、Teamsで普通に話してください。訳は、このページに文字で表示されます。
- EN：During the meeting, speak normally in Teams. Translations appear as text on this page.

### Step 6
- JA：イヤホンを使ってください。ページは閉じないでください。閉じると、それまでの訳が消えます。
- EN：Use earphones. Keep the page open. If you leave the page, the text so far disappears.

### 困ったとき
- JA：①ページを再読み込み（リロード）する ②言語を選び直す ③Teamsのマイクがオンか確認する ④それでも直らなければ、英語で知らせてください。
- EN：(1) Reload the page. (2) Select the language again. (3) Check that your microphone in Teams is on. (4) If it still does not work, tell us in English.

### 英語の定型フレーズ（両方向）
タイ側から：
- "I can't see the Thai text." 
- "The page is not loading."
- "Which passcode should I enter?"
- "Can you hear me?"

日本側から（日本語訳を小さく添える）：
- "Please reload the page." （ページを再読み込みしてください）
- "Please select Thai." （タイ語を選んでください）
- "Please unmute your microphone in Teams." （Teamsのマイクをオンにしてください）
- "Can you see the Thai text now?" （タイ語の文字は見えていますか）
- "Please speak a little slower." （少しゆっくり話してください）

## Ⅴ．画面コピー（髙山が用意する。Claude Code は加工と配置を担当）

(1) 撮り方
髙山が自分のCoeFontアカウントで通訳を開始し、参加者用URLを**PCのブラウザ（Edge/Chrome）とiPhoneのSafari**で開いて撮る。ファイル名は下記に合わせる。

| ファイル名 | 内容 |
|---|---|
| `input/screenshots/pc_01_link.png` | Teamsチャットにリンク・パスコード・QRが貼られた状態（個人情報が写れば黒塗り） |
| `input/screenshots/pc_02_passcode.png` | リンクを開いた直後（パスコード入力画面があればその画面） |
| `input/screenshots/pc_03_language.png` | 言語選択の画面（タイ語の選択肢が見える状態） |
| `input/screenshots/pc_04_translating.png` | 訳が表示されている画面（日本語→タイ語） |
| `input/screenshots/sp_01_qr.png` | iPhoneのカメラでQRを読む場面（任意） |
| `input/screenshots/sp_02_language.png` | iPhoneでの言語選択 |
| `input/screenshots/sp_03_translating.png` | iPhoneでの訳の表示 |

(2) 代替（髙山が撮れない場合のみ）
通訳が起動中で、URLとパスコードを渡せるなら、Claude Code が Playwright で同じページを開き、PC表示（1280×800）とスマートフォン表示（iPhone相当のエミュレーション）で撮ってよい。ただし**ページ上のボタンを押す・言語を選ぶ以外の操作はしない**。

(3) 加工
- 余白を切り、押す場所に番号付きの赤丸を重ねる（Pillow等）。
- 個人名・メールアドレスが写っていればモザイク処理。
- 画面コピーに写っている文言（ボタン名等）を、Ⅳの原稿に**そのまま**反映する。写っていない文言は書かない。

## Ⅵ．制約（必ず守る）

(1) **画面に写っていないボタン名・手順を創作しない。** 不明なところは `[要確認]` と赤字で残す。
(2) **作成ツール名（Claude・Anthropic 等）を成果物に入れない。** メタデータ（PDFの作成者欄）も空か「Nippon Steel Trading Corporation」にする。
(3) タイ語は機械翻訳のため、成果物の末尾（日本語のみ・小さく）に「タイ語は要確認」と残し、別ファイル `output/thai_text_for_review.txt` に、タイ語と英語を対で書き出す（レビュー依頼用）。
(4) 個人情報・社内情報を入れない。URL・パスコードは空欄。
(5) 文は短く。1手順につき、タイ語は2文以内、英語は2文以内。
(6) A4縦2ページに収める。収まらなければ、画面コピーを縮小する。文を削る前に髙山に確認する。
(7) 完成後、Ⅶのチェックリストを自分で確認し、結果を報告する。
