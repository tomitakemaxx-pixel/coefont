# 画面コピー

| ファイル名 | 内容 | 本文 |
|---|---|---|
| `pc_01_link.png` | Teams会議チャットのCoeFontメッセージ（言語タブ・QR・パスコード・ボタン） | 手順2 |
| `pc_02_passcode.png` | パスコード入力と開始ボタン2つ | 手順3 |
| `pc_03_language.png` | 参加者ページ右上の言語設定とイヤホンアイコン | 手順4 |
| `pc_04_translating.png` | 訳の表示画面（左＝原文／右＝訳） | 手順5 |

CoeFont社の公式マニュアル（Teamsプラグイン版・デスクトップ版）から参加者画面だけを切り出し、
`scripts/prepare-screenshots.mjs` で次を処理しています。

- 他社名が写り込んだ画面上部は切り取り
- デモのURL（client_id を含む）とデモのパスコードはグレーで塗りつぶし
- デモのQRコードは誤って読み取られないよう SAMPLE の帯を重ねる

赤い番号丸は画像そのものには入っていません。`src/content.mjs` の `marker` の位置に、
Word文書の作成時に描き込みます。同じ名前で画像を差し替えれば、そのまま使えます。
