# 画面コピーの置き場所

ここに PNG を置くと、ビルド時に**自動で説明用イラストと差し替わります**（再ビルドだけでOK）。
ファイル名は下表のとおりにしてください。名前が一致したものだけ差し替わります。

| ファイル名 | 内容 | 本文の対応 |
|---|---|---|
| `pc_01_link.png` | Teamsチャットにリンク・パスコード・QRが貼られた状態 | Step 2 |
| `pc_02_passcode.png` | リンクを開いた直後（パスコード入力画面） | Step 3 |
| `pc_03_language.png` | 言語選択の画面（タイ語の選択肢が見える状態） | Step 4 |
| `pc_04_translating.png` | 訳が表示されている画面（日本語→タイ語） | Step 5 |

## 赤い番号丸の位置

`src/guide.html` の各図にある `data-marker="x,y"`（画像の左上を 0,0 とした百分率）で指定します。
差し替え後に位置がずれていたら、この数値だけ直してください。番号はステップ番号から自動で入ります。

現在の設定：
- `pc_01_link` → 52,47
- `pc_02_passcode` → 50,55
- `pc_03_language` → 50,48
- `pc_04_translating` → 50,62

## 撮る前の注意

- 個人名・メールアドレス・実URL・実パスコードが写り込んだら、置く前に黒塗りしてください。
- 画面に写っているボタン名・ラベルが本文と違う場合は、**本文を画面の表示に合わせて直します**（`src/guide.html` を編集して再ビルド）。
- 横長（4:3〜16:10程度）で撮ると、図の枠にきれいに収まります。
