# 画面コピー

ここのPNGは、ビルド時に `src/guide.html` の各図へ自動で差し込まれます。
ファイル名が対応関係を決めているので、差し替えるときは同じ名前で上書きしてください。

| ファイル名 | 内容 | 本文 |
|---|---|---|
| `pc_01_link.png` | Teams会議チャットのCoeFontメッセージ（言語タブ・QR・パスコード・ボタン） | Step 2 |
| `pc_02_passcode.png` | パスコード入力と「音声をオンにして開始」「テキストのみで開始」 | Step 3 |
| `pc_03_language.png` | 参加者ページ右上の言語設定とイヤホンアイコン | Step 4 |
| `pc_04_translating.png` | 訳の表示画面（左＝原文／右＝訳） | Step 5 |

## 現行PNGの出どころ

CoeFont社の公式マニュアル（Teamsプラグイン版・デスクトップ版）から参加者画面だけを切り出し、
`scripts/prepare-screenshots.mjs` で次をマスクしています。

- 他社名が写り込んだ画面上部（切り取りで除外）
- デモのURL（client_id を含む）とデモのパスコード（グレーで塗りつぶし）
- デモのQRコード（誤って読み取られないよう SAMPLE の帯を重ねる）

## 赤い番号丸の位置

`src/guide.html` の各図の `data-marker="x,y"`（画像左上を 0,0 とした百分率）で指定します。
空にすると番号丸は付きません。番号はステップ番号から自動で入ります。

- `pc_01_link` → 13,88（「ブラウザで開く」）
- `pc_02_passcode` → 11,46（緑のボタン）
- `pc_03_language` → 指定なし（図そのものが対象）
- `pc_04_translating` → 指定なし

## 自分で撮り直す場合

実際の会議で撮った画面に差し替えるのが理想です。置く前に、実URL・実パスコード・
個人名・メールアドレスが写っていないか確認してください。
